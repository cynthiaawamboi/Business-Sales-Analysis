# Small Business Sales Analysis

## Project Overview
This project analyses sales data from a fictional clothing business to understand its sales performance, revenue generation, and product performance.

The analysis uses Python to transform raw sales data into meaningful business insights.

## Project Objectives
- Calculate total business revenue.
- Identify the best-selling product.
- Identify the product generating the highest revenue.
- Analyse monthly revenue performance.
- Visualise sales performance using charts.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Visual Studio Code

## Key Findings

- Total Business Revenue: KSh 68,200
- Total Units Sold: 42
- Best-Selling Product: T-shirt
- Highest Revenue Product: Sneakers
- Best Performing Month: March 2026

## Monthly Revenue

| Month | Revenue |
|---|---:|
| January 2026 | KSh 16,500 |
| February 2026 | KSh 19,400 |
| March 2026 | KSh 32,300 |
